# 🔁 Loop Utility Programs

This project contains a collection of C++ programs demonstrating fundamental loop-based algorithms and number manipulations. Each menu-driven function showcases a classic use of loops in C++ for mathematical and logical operations.

## 📋 Features

- **Sum of Natural Numbers**: Calculates the sum from 1 to N.
- **Factorial**: Computes the factorial of a number.
- **Reverse a Number**: Reverses the digits of an integer.
- **Palindrome Check**: Checks if a number is a palindrome.
- **Count Digits**: Counts the number of digits in a number.
- **Sum of Digits**: Sums all digits of a number.
- **Prime Check**: Determines if a number is prime.
- **Fibonacci Series**: Prints the Fibonacci sequence up to N terms.

## 🚀 How to Compile and Run

1. Open a terminal and navigate to the `Loop` directory.
2. Compile the code:
   ```sh
   g++ Loop.cpp -o loop_app
   ```
3. Run the executable:
   ```sh
   ./loop_app
   ```

## 🕹️ Usage

- The program displays a menu with options.
- Enter the number corresponding to the operation you want to perform.
- Follow the prompts to input numbers as required.
- Enter `0` to exit.
